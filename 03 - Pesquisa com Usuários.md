# 03 - Pesquisa com Usuários

## 🎯 Objetivo

Conhecer métodos básicos de pesquisa para descobrir necessidades, comportamentos e dificuldades reais.

## 📚 Métodos

### Entrevista

Conversa estruturada ou semiestruturada para compreender experiências e percepções.

### Questionário

Útil para coletar respostas de várias pessoas com perguntas padronizadas.

### Observação

Permite analisar o que as pessoas realmente fazem durante uma tarefa.

### Análise de dados existentes

Podem ser considerados tickets, avaliações, métricas, buscas e registros de atendimento.

## ⚠️ Cuidados

Evite perguntas que induzam a resposta.

Em vez de:

> "Você acha fácil usar este aplicativo?"

Prefira:

> "Conte como você realiza essa tarefa utilizando o aplicativo."

## 📝 Exercícios

1. Crie cinco perguntas para uma entrevista de UX.
2. Identifique quais perguntas são abertas.
3. Explique por que perguntas indutivas podem gerar viés.

## 🚀 Desafio

Crie um roteiro de entrevista para investigar dificuldades em um sistema acadêmico.
