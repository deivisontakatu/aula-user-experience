# 02 - Design Centrado no Usuário

## 🎯 Objetivo

Compreender princípios de Design Centrado no Usuário e aplicá-los na definição de problemas e soluções.

## 📚 Conteúdo

### O usuário como referência

O projeto deve considerar:

- quem utiliza;
- o que precisa fazer;
- em qual contexto;
- quais dificuldades enfrenta;
- quais objetivos possui.

### Problema antes da solução

Evite começar pela pergunta:

> "Qual tela devemos construir?"

Comece por:

> "Qual problema do usuário estamos tentando resolver?"

### Contexto de uso

Considere ambiente, dispositivo, frequência, limitações, experiência prévia e pressão de tempo.

## 📝 Exercícios

1. Escolha um sistema digital.
2. Identifique seus principais usuários.
3. Descreva três necessidades.
4. Registre três possíveis problemas de experiência.

## 🚀 Desafio

Escreva um problema de UX no formato:

**Usuário + situação + dificuldade + impacto.**
