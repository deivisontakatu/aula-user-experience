# 09 - Acessibilidade e UX Inclusiva

## 🎯 Objetivo

Compreender como acessibilidade influencia a experiência e ampliar o acesso às interfaces.

## 📚 Princípios práticos

### Teclado

Todas as ações essenciais devem ser utilizáveis sem depender exclusivamente do mouse.

### Foco

O usuário precisa perceber qual elemento está em foco.

### Semântica

HTML semântico melhora compreensão e interação assistida por tecnologias.

### Contraste

Textos e controles precisam apresentar contraste suficiente para leitura e identificação.

### Formulários

Campos devem possuir labels claros, mensagens de erro compreensíveis e instruções adequadas.

## 📝 Exercícios

1. Navegue pelo exemplo usando apenas o teclado.
2. Identifique elementos sem foco visível.
3. Verifique se os campos possuem labels.
4. Liste três melhorias de acessibilidade.

## 🚀 Desafio

Revise uma página web considerando navegação por teclado e comunicação de erros.
